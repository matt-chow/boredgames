# Crown Project end rule experiment

Generated by `npm run experiment:crown-end`. An experiment only: the game still ends at 4 of 5 Projects. DECISIONS.md D35 says what it
shows and what it can't. 80 seeded games for each
rule and each of 2 to 6 players, 1200 in all, on the Standard game (Core and Crown Decrees). Each rule plays the same
seeds, markets, Projects, bots and seats, and only the end rule differs. Every other way to end the game is unchanged: the Grand Duchy
pile running out, or 3 market piles running out (4 at 5 or 6 players).

- **A.** Current: ends at 4 of 5 Projects.
- **B.** Projects never end the game.
- **C.** Ends when all 5 are claimed.
